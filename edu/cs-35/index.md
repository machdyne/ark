# First Programs

A computer does exactly what a program tells it, one step at a time.
In this course you write programs in BASIC on the BASIC computer: you
make it print, count, ask questions, choose, repeat and draw. Then you
find out how a computer keeps numbers as bits, how a message finds its
way across the internet, and how to stay safe online.

Do the parts in order. Keep the BASIC computer open beside the lessons
and type the programs in yourself: that is how you learn them.
